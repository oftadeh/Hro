# کی‌فیت (KeyFit) — سوپر اپ سلامتی

یک اپ، یک اشتراک، یک کیف پول: ورود بدون ثبت‌نام به باشگاه‌ها، مشاور هوشمند و مربی، فروشگاه، پزشک، غذای رژیمی، شبکه‌ی اجتماعی و چالش‌های جایزه‌دار.

## اجرا

```bash
cd web
npm install
npm run dev      # http://localhost:5173
npm run build    # خروجی تولید در web/dist
```

در صفحه‌ی ورود، با دکمه‌های «ورود سریع» می‌توانید با هر نقش وارد شوید. ورود با موبایل هم کار می‌کند (کد تایید آزمایشی: `1234`).
از پروفایل → «بازنشانی داده‌های نمایشی» داده‌ها به حالت اول برمی‌گردند.

## نقش‌ها و پنل‌ها

هر کاربر می‌تواند چند نقش داشته باشد و از سوئیچر نقش بین پنل‌ها جابجا شود. هرچه در پنل ثبت شود در ماژول مربوطه به کاربر نمایش داده می‌شود.

- **باشگاه‌دار** `/panel/gym` — معرفی باشگاه (نقشه، عکس، فیلم، قیمت سانس)، پذیرش ورود با کد، آمار
- **مربی** `/panel/coach` — پروفایل و پکیج‌ها، سفارش برنامه و تحویل آن، گفتگوها
- **فروشنده** `/panel/seller` — محصولات، موجودی، تخفیف، سفارش‌ها
- **پزشک** `/panel/doctor` — زمان‌بندی نوبت، ثبت نتیجه‌ی ویزیت
- **رستوران** `/panel/restaurant` — منو با اطلاعات تغذیه‌ای، سفارش‌ها
- **مدیر** `/panel/admin` — نمای کلی درآمد و گردش مالی، کاربران، تایید باشگاه‌ها، دفتر کل و تسویه‌ها، چالش‌ها، تنظیم کمیسیون هر ماژول

همه‌ی نقش‌های ارائه‌دهنده بخش «درآمد و تسویه» دارند (درخواست برداشت با شبا → تایید مدیر).

## مدل مالی

همه‌ی پرداخت‌ها از یک هسته (`web/src/core/services/ledger.ts`) عبور می‌کنند:

- **سانس باشگاه:** از اعتبار اشتراک (یا کیف پول) کسر → کمیسیون فیت‌یاب به کی‌فیت → باقی به کیف پول باشگاه‌دار
- **مربی / پزشک / فروشگاه / بوفه:** کیف پول کاربر → ارائه‌دهنده، با کمیسیون همان ماژول
- **چالش:** هزینه‌ی ساخت کامل به کی‌فیت؛ ورودی‌ها پس از کسر کمیسیون + جایزه‌ی اسپانسر در صندوق امانی (escrow)؛ در پایان، صندوق طبق درصد جوایز به برندگان پرداخت می‌شود
- **اشتراک:** مبلغ به کی‌فیت؛ کاربر اعتبار بیشتری از مبلغ پرداختی برای ورود به باشگاه‌ها می‌گیرد
- **مزایای اشتراک** (`core/services/perks.ts`): تخفیف درصدی ماژول‌ها، ورود رایگان به چالش و ویزیت رایگان پزشک. تخفیف از سهم کی‌فیت کسر می‌شود و ارائه‌دهنده همیشه سهم کامل خود را می‌گیرد؛ در دفتر کل به‌صورت فیلد `discount` ثبت می‌شود

| پلن | مزایا |
|---|---|
| نقره‌ای | ۱۰٪ بوفه، ۵٪ فروشگاه |
| طلایی | ۱۵٪ فروشگاه و بوفه، یک ورود رایگان به چالش، نشان ویژه در فیت‌زون |
| الماس | ۲۰٪ فروشگاه، بوفه، مربی و پزشک، یک ویزیت رایگان، دو ورود رایگان به چالش، نشان ویژه |
- لغو سفارش، مبلغ کامل را به خریدار برمی‌گرداند

درصد کمیسیون هر ماژول از پنل مدیر قابل تغییر است.

## زبان طراحی

آرام و شاعرانه، با تم تیره‌ی پیش‌فرض: پس‌زمینه‌ی زغالی-بنفش، گرادیان‌های پاستلی (یاسی، صورتی، نعنایی، هلویی)، گوی‌های رنگی محو، تیترهای سریف با قلم «مرکزی» (Markazi Text) و متن با «وزیرمتن»، بخش‌های لایه‌ای رنگی، نمودار ستونی باریک و نمودار حلقه‌ای چندرنگ. تم روشن هم پشتیبانی می‌شود.

تصویرسازی‌ها و کاراکترهای متحرک (دونده، وزنه‌بردار، دوچرخه‌سوار، یوگا، مربی، پزشک، لیوان آب، قلب، جام، کاسه‌ی سالاد، شیکر، کیف پول، ترازو، شعله، نقشه و ربات) به‌صورت SVG درون‌خطی در `web/src/ui/art.tsx` هستند و انیمیشن‌ها با کلاس‌های `kf-*` در `index.css`. شمارنده‌ی اعداد، رشد نمودارها، ورود پله‌ای کارت‌ها و حرکت گوی‌ها در `web/src/ui/motion.tsx` و کیت پیاده شده‌اند. با فعال بودن «کاهش حرکت» در سیستم، همه‌ی انیمیشن‌ها غیرفعال می‌شوند.

همه‌ی اجزا در `web/src/ui/kit.tsx` و رنگ‌ها در `web/tailwind.config.js` تعریف شده‌اند.

## معماری (آماده برای توسعه به موبایل)

```
web/src/
  core/          ← منطق دامنه، مستقل از UI و پلتفرم
    types.ts       مدل‌های داده
    config.ts      نقش‌ها، پلن‌ها، کمیسیون پیش‌فرض، سطح‌ها
    db.ts          ذخیره‌سازی (فعلاً localStorage)
    services/      همه‌ی عملیات: wallet، fityab، fityar، commerce، doctor، fitzone، challenges، admin، auth، engagement
    ai/            قرارداد ارائه‌دهنده‌ی هوش مصنوعی + مشاور آفلاین
  ui/            کیت طراحی (دکمه، کارت، شیت، تب، ...)
  layouts/       قالب اپ کاربر و قالب پنل نقش‌ها
  modules/       ماژول‌های کاربر
  panels/        پنل هر نقش
  pages/         صفحات عمومی (خانه، کیف پول، پروفایل، ...)
```

- **UI فقط سرویس‌های `core/services` را صدا می‌زند.** برای اتصال به سرور واقعی، بدنه‌ی سرویس‌ها با فراخوانی API جایگزین می‌شود و صفحات تغییری نمی‌کنند. منطق مالی سرویس‌ها باید سمت سرور اجرا شود.
- **پوشه‌ی `core`** هیچ وابستگی به DOM ندارد (به‌جز `localStorage` در `db.ts`) و می‌تواند به یک پکیج مشترک برای React Native منتقل شود.
- **موبایل:** سریع‌ترین مسیر [Capacitor](https://capacitorjs.com) است — همین خروجی `dist` به اپ اندروید و iOS تبدیل می‌شود (`npx cap add android`). اپ از قبل `manifest` و `viewport-fit=cover` دارد و به‌صورت PWA قابل نصب است.
- **هوش مصنوعی:** با تنظیم `VITE_AI_API_URL` (نمونه در `web/.env.example`) گفتگو به سرور شما فرستاده می‌شود (`POST { messages, profile } → { text, suggestions? }`) تا به یک مدل زبانی وصل شود؛ کلید API هرگز نباید در فرانت‌اند باشد. بدون آن، مشاور آفلاین با محاسبات BMR/TDEE و قالب‌های برنامه پاسخ می‌دهد.

## گام‌های بعدی پیشنهادی

1. بک‌اند (مثلاً NestJS + PostgreSQL) با همان مدل‌های `core/types.ts`؛ احراز هویت OTP واقعی (پیامک)
2. درگاه پرداخت (زرین‌پال / آی‌دی‌پی) برای شارژ کیف پول
3. سرور هوش مصنوعی فیت‌یار
4. تماس صوتی/تصویری با WebRTC، اعلان پوش
5. اتصال قدم‌شمار گوشی (Health Connect / HealthKit) برای ثبت خودکار چالش‌ها
