# اپ اندروید کی‌فیت (Capacitor)

این اپ همان سایت **keyfitapp.ir** را داخل یک اپ بومی اندروید باز می‌کند؛ پس هر به‌روزرسانی سایت بدون نصب نسخه‌ی جدید به دست کاربران اپ هم می‌رسد. فقط تغییر آیکن، نام، مجوزها یا نسخه نیاز به ساخت دوباره دارد.

## آنچه اپ دارد
- آیکن و صفحه‌ی آغاز با رنگ برند، نام «کی‌فیت»، شناسه‌ی `ir.keyfitapp.app`
- دسترسی دوربین (اسکن QR ورود باشگاه) و موقعیت (دکمه‌ی «موقعیت من» و نقشه)
- پرداخت زرین‌پال داخل خود اپ و بازگشت به اپ پس از پرداخت
- لینک‌های بیرونی (مسیریابی نشان/گوگل‌مپ/ویز، تماس تصویری) در اپ یا مرورگر گوشی باز می‌شوند
- صفحه‌ی «اتصال به اینترنت برقرار نیست» با دکمه‌ی تلاش دوباره
- نمایش تصویر مدارک داخل اپ (PDF فقط در نسخه‌ی وب)

محدودیت فعلی: اعلان‌های Push مرورگر داخل اپ کار نمی‌کند؛ اعلان‌های داخل برنامه برقرار است.

## گرفتن فایل APK (بدون نیاز به نصب Android Studio)
ساخت روی GitHub Actions انجام می‌شود:
1. در گیت‌هاب مخزن، تب **Actions** ← **Android (Capacitor)** ← **Run workflow** (یا هر تغییری در پوشه‌ی `mobile`).
2. پس از پایان (حدود ۱۰ دقیقه)، از بخش **Artifacts** فایل `keyfit-debug-…` را دانلود کنید.
3. فایل zip را باز کنید و APK را روی گوشی نصب کنید (نصب از منابع ناشناس را موقتاً مجاز کنید).

نسخه‌ی debug برای آزمایش است و در بازارها منتشر نمی‌شود.

## نسخه‌ی نهایی امضاشده (برای کافه‌بازار، مایکت، گوگل‌پلی)
کلید امضا را **خودتان** بسازید و نگه دارید؛ گم شدنش یعنی امکان به‌روزرسانی اپ در بازار از بین می‌رود.

```bash
keytool -genkeypair -v -keystore keyfit.jks -alias keyfit -keyalg RSA -keysize 4096 -validity 10000
base64 -w0 keyfit.jks > keyfit.jks.b64
```

سپس در گیت‌هاب: **Settings ← Secrets and variables ← Actions** این چهار مقدار را اضافه کنید:

| نام | مقدار |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | محتوای فایل `keyfit.jks.b64` |
| `ANDROID_KEYSTORE_PASSWORD` | رمز keystore |
| `ANDROID_KEY_ALIAS` | `keyfit` |
| `ANDROID_KEY_PASSWORD` | رمز کلید |

از اجرای بعدی، علاوه بر نسخه‌ی debug، فایل‌های `keyfit-1.0.N.apk` (برای بازارهای ایرانی) و `keyfit-1.0.N.aab` (برای گوگل‌پلی) امضاشده در Artifacts قرار می‌گیرد. شماره‌ی نسخه خودکار از شماره‌ی اجرا می‌آید.

## ساخت روی کامپیوتر خودتان (اختیاری)
نیازها: Node 22، JDK 21، Android Studio (SDK 35)، ImageMagick

```bash
cd mobile
npm install
npm run android:add   # فقط بار اول
npm run icons
npm run android:sync
cd android && ./gradlew assembleDebug
```
